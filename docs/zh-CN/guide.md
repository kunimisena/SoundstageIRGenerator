# 耳机空间音效与 HRTF 卷积核使用指南

[English](../en/guide.md) · [回到首页](../../README.md)

Soundstage IR Generator 生成双耳空间音效的四路径脉冲响应（IR），供 Equalizer APO 或矩阵卷积器播放。HRTF（头相关传递函数）描述不同方向到两耳的响应，混响参数决定空间的湿度、频谱与拖尾。

## 三个页面

| 页面 | 用途 |
|---|---|
| 模板选择 | 选择十套声场或空白模板；弹窗编辑整体曲线与方向分布 |
| 配置 | 调整直达声、人头、混响比例、随机细节和 EQ，生成并查看卷积结果 |
| 导出与后处理 | 导出 WAV、Equalizer APO 配置，或处理歌曲 |

点击模板卡片打开参数窗口。**确认**载入参数并进入配置页；**确认并生成卷积核**还会开始计算。取消保留当前配置。模板页下方也提供“导入配置…”入口。

模板参数窗口包含能量频谱、衰减时间、完整包络三张整体编辑图及方向生成器。回到模板选择页，点击“调整当前模板…”可以继续调整这一步。取消保留当前项目；确认才载入修改。

配置页左侧调整人头、直达声、混响比例、随机细节和 EQ，右侧显示结果；拖动中间的分隔条调整两边比例。窄窗口改为上下排列，分隔条也随之改为上下调节；恢复宽窗口时使用设定的左右比例。“反射源详细配置…”打开独立窗口，编辑方向、多选、分组和单源 L/R 激励。窗口底部“完成”关闭编辑窗口，参数保留在当前项目中。

结果图旁依次排列“生成卷积核”“导入配置…”和“导出配置…”，进度与结果状态显示在下方。导入和导出使用 JSON 配置文件，包含参数与随机种子；导出配置无需先生成卷积核。配置名称、卷积核采样率和输出增益在生成区填写；撤销和重做按钮也位于这里。修改参数后，图表显示已完成的结果，并标记“参数已修改 · 图表待更新”。

整体曲线或方向分布改变后，模板向下重新生成反射源；逐源细调独立保存。重新打开模板但保持整体曲线不变，会保留逐源细调。确认新的模板设置后可以在配置页撤销。

导出页也提供“生成卷积核”，并直接显示能否导出的原因：尚未生成、参数已修改、正在生成，或当前结果可导出。WAV、APO 和歌曲处理使用同一份当前卷积结果。歌曲处理位于导出页内。所有折叠区初始展开，点击带箭头的标题或右侧“收起／展开”切换。

图表分析按生成结果缓存。拖动窗口边缘调整大小时，页面暂时显示缩放预览，松开后重新排版并恢复清晰图表。左右分栏与上下排列也在松开后切换。主窗口、模板参数窗口及反射源窗口都采用这一方式。图例、缩放和平移操作复用曲线路径和文字绘制。

导出路径、结果信息和处理状态支持鼠标选中与 Ctrl+C。点击“复制路径”可复制 WAV 或 APO 导出目录，点击“复制结果信息”可复制完整分析文字。

导出页显示当前导出名称。套用模板会更新配置名称并清除上次导出路径；修改配置名称后，WAV、APO 与 JSON 文件名同步使用新名称。单纯改名可直接导出，卷积核样本保持不变。

## 先动这几个参数

1. **人头模型**：内置模板使用 FABIAN，默认开启“去除共同频响”。可切换到球形头模型，模拟头部遮挡和到耳时差。配置文件记录所选模型及其参数。
2. **混响能量占比**：决定直达声和混响的整体比例。比逐源改增益更适合调整干湿感。
3. **整体衰减时间倍率**：改变拖尾长短；算法会重标定能量，不会只因为尾巴更长就增加设定的总能量。
4. **频谱轮廓**：用宽范围的变化调整反射声的颜色；它与总输出 EQ 含义不同。
5. **二级 EQ 强度**：默认 0%。想补偿同相测试响应时逐渐增加，再用实际音乐比较。

先保持相同种子，一次改一项。对比时尽量匹配响度。

内置模板的默认设置为 FABIAN、开启“去除共同频响”、关闭“强制随机镜像”、一级 EQ 100%、二级 EQ 0%。每套模板都可以继续调音，并通过“导出配置…”保存完整参数。

宽阔监听是作者的听感推荐，表中列出各方向参数范围；直达声空气吸收距离为 5 m，一级平滑为 1/12 oct。其他模板一级为 1/12，二级强度均为 0%。内置源的默认数值实际取到三位小数，随机标识保留。用户输入的精度在编辑、保存和生成时保持一致。

控制室以 5% 反射能量、克制早段和轻量短尾为起点，反射频谱在中高频逐渐降低。自由场保留人头和输出 EQ 设置，反射源为零、混响比例为 0%。

## 相对权重与混响百分比

源电平和频谱的 0 dB 是公共参考，不强迫某个源恰好为 0 dB。所有源统一 −6 dB 与统一 0 dB，在同一混响比例下给出相同的归一化结果；相互之间的差异才决定方向权重。

百分比的定义是 `Ewet / (Edry + Ewet)`，目标对应头部处理、最终 EQ 与带通之后的结果，以 20 Hz–20 kHz 平坦功率谱、左右独立等功率输入为参考，对两耳累计。干湿交叉项不计入这个分量比例；歌曲听感还受到输入声道相关性的影响。25% 对应 wet/dry = 1/3。

生成时先保留直达声与混响的频谱，计算 EQ 带来的比例偏移，再求一个整体混响增益作预修正。所有反射方向、输入和频段共用这个标量；源之间的相对权重、频谱形状、相位和时间包络保持原样。两级 EQ 根据预修正后的合成响应设计。结果显示目标、EQ 前与最终实测占比，实际输出仍经过原有共同增益标定；有限核长或未收敛带来的占比残差会显示提示。

关闭“启用直达声”时，混响占比显示为 100%，输入框与滑条暂停调节；重新启用后恢复关闭前的占比。模板参数窗口显示相同的状态，配置文件保存开关及原占比。

## 三条曲线

- **能量频谱**：整条方向核的宽尺度能量轮廓。频率为对数轴，控制点保形插值。
- **衰减时间尺度**：各频段的衰减时间尺度。自定义非指数包络时，它是尾长参考尺度，不等于任意测量算法拟合出的 RT60。
- **完整包络**：局部平均能量的演变，横轴是相对直达的额外累计路程。能量衰减图另外显示反向积分的 EDC。建立段可上升、持平或下降，反射变密不必意味着能量上升。

首反额外路程 / 343 给出相对直达的起点。反射变密路程控制建立段和反射密度尺度。空气吸收距离另管直达声的频率损耗，不是音箱位置，也不直接施加自由空间距离电平或传播等待。显示零点取同侧直达参考主峰；实际文件仍保留共同前导样本和双耳时差。

默认衰减范围 0.005–30 s，路程 0–3430 m，空气吸收 0–10000 m。极端参数会钳位；更长的核需要更多内存和时间。



成品四路径使用共同标量校准到设定的输出参考电平，保留相对电平和时差。结果信息与导出说明列出频点增益及瞬态峰值上界，供设置播放余量；这些数值仅作提示。

二级 EQ 旁路时，整体标定及残差以两耳各自的响应为参考；启用二级时，以其两耳复响应平均为参考。残差按设定的输出参考电平计算。生成提示可在图表下方的提示条悬停查看，导出页的“结果信息”列出完整内容。

## 镜像、方向与随机数

只编辑左半边参数，右半边始终镜像并交换 L/R 输入；对称面源不重复。强制随机镜像默认关闭：镜像双方的统计参数相同，随机实现可不同。打开后强制样本级镜像，EQ 使用共同一级。

同一方向的 L/R 激励默认独立；自动 R 继承 L 时间参数，通过相对增益和 tilt 调整频谱。可以改成完整手动编辑。不同方向并不直接复制同一条噪声；同一方向、同一输入的核则同时送往两耳各自的人头滤波器。

普通修改不刷新其他源的随机实现。复制源或粘贴参数会分配独立随机细节；稳定 ID 和种子保存于项目。方向生成支持水平、球形、半球、前向与镜像成对分布，上限 32；增加方向数不意味着必然更好听。

## EQ 和图表

一级对每耳同相输入响应做平滑最小相位校正，默认 100%、1/12 oct。二级对一级之后的两耳复响应平均设计共同 EQ，默认 0%、1/3 oct。滑条改变校正 dB 的比例；0% 完全旁路。两级均按平滑目标计算完整增益。内部使用双精度，平滑分析覆盖带通的过渡带。一级与二级校正和带通目标在频域合成四路径；时间预算由原始响应长度决定，短场景保留一秒带通支撑。强修正、平滑残差和有限长度合成偏差会在生成提示中列出。

二级 EQ 以两耳同相响应的复数平均为参考，对最终四条路径共同施加校正。

分析可以查看最终路径、直达、当前反射源、人头前激励、EQ 滤波器和同相响应；图型包括频响、IR、EDC、相位和群延迟。滚轮缩放、拖动平移，双击绘图区或点“复位视图”恢复坐标。点击图例开关曲线，双击或右键独看，点“显示全部曲线”恢复。显示平滑只改变绘图，不改变卷积核。

## 导出和路由

文件夹采用 `模板名_日期_时间`，改名项目还会包含项目名。四条 WAV、路径包、JSON 和配置都带同一名称前缀；重名使用 `_02` 等序号，不覆盖原文件。

下表为文件名后缀，名称始终表示“输入 → 耳朵”：

| 文件 | 路径 |
|---|---|
| `L_to_LeftEar.wav` | 左输入到左耳 |
| `R_to_LeftEar.wav` | 右输入到左耳 |
| `L_to_RightEar.wav` | 左输入到右耳 |
| `R_to_RightEar.wav` | 右输入到右耳 |

`Matrix_PATHS_LL_RL_LR_RR.wav` 按上表顺序打包四条路径，供支持矩阵路由的卷积器读取。

APO 导出会生成使用绝对路径的 `模板名_APO.txt`；将它 Include 到自己的配置。卷积后赋值 `L=LL+RL R=LR+RR`，得到处理后的双声道输出。移动导出文件后需重新导出。设备与核的采样率应一致。普通 WAV 导出也提供对应 APO 路由文件。

参考增益、峰值界限和共同前导见导出说明，可据此设置播放增益。20 Hz 和 20 kHz 位于通带，陡峭边沿在范围外。

## 处理歌曲

在“导出与后处理 → 处理歌曲”里点击“选择 ffmpeg.exe…”，选择完整 FFmpeg 构建中的程序文件，同目录需有 `ffprobe.exe`，构建需支持 libsoxr。选择后自动检查，也可点击“检查可用性”重新检查。支持 WAV、FLAC、MP3、M4A 等输入，处理后导出 WAV、FLAC 或 M4A，并保留卷积尾部。

路径单独保存在程序工作目录的 `settings/audio-tools.json`，不进入声场项目 JSON；导入其他配置不会覆盖本机工具路径。“自动查找”清除手动选择并搜索程序旁 `tools/ffmpeg/`、`%ProgramFiles%/ffmpeg/bin/` 与 PATH。手动路径失效时提示重新选择，不会悄悄改用另一个构建。

工具检查会验证版本、卷积参数和重采样／响度／限幅功能；歌曲处理前再次检查。下载：[FFmpeg](https://ffmpeg.org/download.html)。来源与许可见项目根目录 `THIRD_PARTY_NOTICES.md`。

支持 mono/stereo 输入，自动重采样到当前核采样率，保留曲终拖尾；输出 float32 WAV、24-bit FLAC、AAC/M4A。输入不被覆盖。

- 默认：扫描卷积后响度，固定增益到 −18 LUFS，再双声道联动限幅。
- 仅限幅：不做 LUFS 增益补偿；触发限幅和编码安全修正时仍可能改变响度。
- 旁路：用于分析原始处理结果。

−18 LUFS 是分享用的默认目标。成品会重新测量，实际响度和真峰值记录在 `render.json`。

## 数据放在哪里

完整便携文件夹可复制；配置、卷积文件、APO 配置和处理后歌曲分别在 EXE 旁的 `projects/`、`exports/`、`EqualizerAPO/`、`processed-audio/`。放在有写权限的目录。发布包不包含别人的个人数据；不要直接把自己使用过的整个文件夹上传 GitHub。

幅频图默认显示 20 Hz–20 kHz。勾选“显示带通范围”可将范围扩展到 5 Hz 起、低至 −100 dB，用于检查带通衰减；取消勾选恢复常用范围。该选项只影响显示。
