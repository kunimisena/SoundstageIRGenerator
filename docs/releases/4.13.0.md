# Soundstage IR Generator 4.13.0

## 中文

界面支持简体中文与英文，可在窗口右上角切换，语言选择自动保存。首次启动时，中文系统使用简体中文，其他系统使用英文。

- 页面、模板介绍、参数说明、图表、状态信息及导出说明支持两种语言。
- 切换语言保留当前配置、已生成的卷积核、选中项、图表缩放和隐藏曲线；图表复用已有分析结果。
- 用户填写的配置名、反射源名和文件路径保持原样。英文界面从内置模板新建配置时使用英文默认名称；配置 JSON 可在两种语言下使用。
- 中英文使用指南与离线帮助同步更新。

声学生成、人头处理、EQ 与能量归一化算法保持不变。同一配置在两种语言下生成的四条卷积核逐样本一致。双语功能通过 67 项定向检查，包含配置读写、全部模板、图表状态和 WAV 回读；详见[验证记录](https://github.com/kunimisena/SoundstageIRGenerator/blob/main/docs/VALIDATION.md)。

下载 `SoundstageIRGenerator-4.13.0-win-x64.zip`，解压后运行文件夹中的 `SoundstageIRGenerator.exe`。

## English

The interface supports English and Simplified Chinese. Choose a language at the top right; the application remembers your choice. On first launch, Chinese systems use Simplified Chinese and other systems use English.

- Pages, template descriptions, parameter explanations, plots, status messages and export instructions are available in both languages.
- Switching language retains the current configuration, generated kernels, selections, plot zoom and hidden curves. Plots reuse cached analysis data.
- User-defined configuration names, source names and file paths remain unchanged. Built-in templates created in English receive English default names. Project JSON files work in either language.
- Both user guides and the offline help have been updated.

Acoustic generation, head processing, EQ and energy normalization algorithms are unchanged. The same configuration produces sample-identical kernels in both languages. The bilingual feature passed 67 targeted assertions covering project persistence, all templates, plot state and exported WAV samples. See the [validation record](https://github.com/kunimisena/SoundstageIRGenerator/blob/main/docs/VALIDATION.md).

Download `SoundstageIRGenerator-4.13.0-win-x64.zip`, extract it and run `SoundstageIRGenerator.exe` inside the folder.
