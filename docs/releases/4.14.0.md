# Soundstage IR Generator 4.14.0

## 中文

发布包增加音箱应用 `SoundstageSpeakers.exe`，与耳机应用共用统计核、曲线和文件处理组件。

- **简单混响**：左右两条核，独立随机细节，可联动能量频谱、衰减和包络；校正后的干湿能量占比可调。
- **复杂空间音效**：生成目标双耳声场，再通过实际音箱摆位模型转换为四路径驱动核。实际角度、仰角与距离分别配置。
- 自由场 F 与目标 T 均使用原耳机版的校准／EQ 链路，直接求解 F × C ≈ T；保留窄谷求逆约束，显示实际因果延迟。
- 复杂模式模板确认后进入配置，按实际音箱、虚拟音箱、人头设置排列；实际音箱空气吸收默认开启，采用远场方向响应。
- 频响图上限随可见曲线自动扩展；复杂模式图表分为五组，新增实际求逆算子的幅频、相位和群延迟图。
- 模式选择说明各自适用场景；虚拟音箱角度旁提示大角度差引起的相消风险。
- 参数预检查标红说明几何风险；生成后显示相消代价、还原误差和固定七个位置的频响标准差。
- 图表切换防止重入，取消过期任务；支持目标与串联响应叠图及 APO 串联对照配置。
- 启动引导选择模式；主窗口、模板卡片、曲线编辑器、结果和导出页面直接复用耳机版。最终 L/R 响应、四路径及相位／群延迟分析完整保留。
- 中英文界面、项目读写、WAV／APO 导出与歌曲处理。
- Equalizer APO 导入文件以 `Equalizer_APO配置`／`Equalizer_APO_Config` 明确命名，辅助说明使用其他名称。

耳机版声学生成链路保持原样。音箱版的模型和使用方法见[指南](../zh-CN/speakers.md)。

## English

The portable package adds `SoundstageSpeakers.exe`, sharing synthesis, curve and file-processing components with the headphone application.

- **Simple reverb**: two kernels with independent random detail, linked or separate energy/decay/envelope curves, and calibrated wet energy.
- **Complex spatial audio**: a desired binaural field is converted into four loudspeaker-drive paths using the actual azimuth, elevation and distance of each speaker.
- Free field F and target T both use the headphone calibration/EQ chain; solve F × C ≈ T directly, with narrow-notch constraints and an explicit causal delay.
- Complex templates confirm into configuration, ordered as actual speakers, virtual speakers and head settings. Actual-speaker air absorption defaults on, with a far-field directional model.
- Magnitude plots automatically expand their upper axis. Complex-mode plots use five groups and include the actual inverse operator’s magnitude, phase and group delay.
- Mode cards describe intended users, and virtual-angle controls explain the cancellation risk of large actual/virtual angle differences.
- Red parameter prechecks explain geometry risks. Generated results report cancellation cost, reconstruction errors and response standard deviation across seven fixed poses.
- Plot switching avoids re-entrant selector updates and cancels obsolete work. Target/cascade overlays and an APO cascade-comparison configuration are included.
- Startup mode guide; the main window, template cards, curve editors, results and export pages reuse the headphone application. Final L/R responses, individual paths, phase and group-delay analysis are available.
- Chinese and English UI, project files, WAV/APO export and offline song processing.
- Clearly named `Equalizer_APO_Config` / `Equalizer_APO配置` import files, with separately named supporting notes.

The headphone synthesis chain is retained. See the [speaker guide](../en/speakers.md) for the model and workflow.
