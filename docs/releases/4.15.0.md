# Soundstage IR Generator 4.15.0

## 中文

复杂空间音效增加可调求逆频带，在指定频段转换方向声场，并用独立的低频、高频统计混响连接两侧。

- 用户人头求逆默认范围为 **200 Hz–10 kHz**，支持滑条和数值输入；设置 **20 Hz–20 kHz** 使用完整求逆链路。
- 两侧混响的能量和衰减曲线分别编辑、保存和生成。带内由方向声场决定，没有额外的隐藏曲线；分频边界点可上下调整。
- 移动分频点会裁剪或延伸对应一侧曲线，一次拖动可一次撤销。过渡区延续本侧边缘值，独立混响按功率互补权重衔接。
- 合成后校准整体混响能量占比，并显示最终预测耳端的直达、混响和共同 EQ。
- 求逆设置位于人头设置下方。修复编辑曲线与拖动求逆频带时的页面跳动；预检查提示更新保持固定布局。
- 启动模式窗口遵循系统语言，手动选择的中英文偏好可保存。

[音箱使用指南](https://github.com/kunimisena/SoundstageIRGenerator/blob/main/docs/zh-CN/speakers.md)

## English

Complex spatial audio gains an adjustable inverse bandwidth, combining the directional target with separate low- and high-frequency statistical reverbs.

- The listener-head inverse defaults to **200 Hz–10 kHz**, with sliders and numeric input. Select **20 Hz–20 kHz** to use the full inverse pipeline.
- Low and high reverb energy/decay curves are edited, stored and synthesized separately. The middle uses the directional field, without additional hidden curves. Crossover endpoint values remain editable.
- Moving a crossover trims or extends that side, with one-step undo. Edge values continue into power-complementary transitions between independent reverbs.
- The combined result is calibrated to the overall wet-energy setting. Analysis includes predicted-ear direct and wet components and common EQ.
- Inverse controls follow head settings. Curve edits and crossover changes keep the page stable while the parameter precheck updates in a fixed layout.
- The startup mode dialog follows the system language and preserves explicit Chinese/English preferences.
