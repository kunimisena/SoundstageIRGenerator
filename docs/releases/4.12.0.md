# Soundstage IR Generator 4.12.0

## 中文

将已试听确认的两项 FABIAN 处理整合为正式流程，移除试验开关。

- **带外边缘延伸。** 保留 20 Hz–20 kHz 的方向响应与深谷，带外幅度沿用各方向、各耳的对应边缘值。直接由原生数据重建目标采样率，删除 −40 dB 幅度下限。
- **非相干人头功率校正。** 使用全部启用方向的等能量单位冲激测试，双耳功率平均后直接求逆；不引入方向间相干相消或随机混响细纹。共同校正位于原有每耳／中置两级 EQ 之前。
- **固定集成。** 配置文件与界面不再包含两项试验开关。整体 EQ 总开关、两级强度、CTF 选项、球形头对照、混响占比与共同输出归一化保留。
- **说明同步。** 更新中英文设计说明、离线帮助、FABIAN 变换说明与导出元数据。

原有配置可直接载入，重新生成后应用正式处理。作者认可的宽阔监听结果已与两项均开启的 4.12.0-preview.3 核对，四条最终卷积核逐样本一致；验证结果见 [构建记录](https://github.com/kunimisena/SoundstageIRGenerator/blob/main/docs/VALIDATION.md)。

## English

This release integrates the two auditioned FABIAN operations into the standard signal path and removes their experimental switches.

- **Boundary-magnitude extension:** preserve directional magnitudes and notches within 20 Hz–20 kHz, and extend each ear/direction's edge magnitude outside that band. Reconstruct directly from native data at the output sample rate. The −40 dB floor is removed.
- **Noncoherent head-power calibration:** test every enabled direction with an equal-energy unit impulse, average binaural powers and apply a common minimum-phase inverse before the existing per-ear and center EQ stages. The reference contains neither coherent inter-direction cancellation nor random reverberation detail.
- **Fixed integration:** the two experiment flags are removed from the UI and project format. Master EQ bypass, tonal strengths, CTF selection, spherical-head comparison, wet balance and common output normalization retain their roles.
- **Updated documentation:** bilingual design notes, offline help, FABIAN modifications and export metadata describe the complete processing chain.

Load existing projects and regenerate their kernels to apply the standard processing. Validation includes a sample-by-sample comparison against the accepted preview.3 configuration with both operations enabled. See the [validation record](https://github.com/kunimisena/SoundstageIRGenerator/blob/main/docs/VALIDATION.md).

Download `SoundstageIRGenerator-4.12.0-win-x64.zip` and run the executable inside. Source and SHA-256 files are included with the release.
